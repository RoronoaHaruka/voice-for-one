## 一、账号与钱

**月抛成品号最划算。** Haruka 原话：「我支持月抛成品号啊！！！40一个月，13万（额度）。订阅咋也得七八十。」「一个月省一百块钱呢比自己订阅。」

- 月抛号到期就换：每次重新拉一个 API key，用**同一份音源**重新克隆音色。Haruka：「我每个月都重新用一模一样的音源克隆，声音都很稳定。」
- 克隆出来的音色**不跟账号走**，换号就得重克。所以把克隆用的音源固定存成一个文件夹，换号时一键重来，几分钟的事。
- 过期号的 key 和 voice ID 全部作废归档，别拿旧脚本里的编号去试跑，一定会乱。
- 免费版每月一万额度，**但免费版不能克隆**。
- **6 刀那档（Starter）完全够用**，Haruka：「完全够！」要是买月抛成品号，这一档大概二十多块。
- **小心首月优惠的续费陷阱**：22 刀那档（Creator）首月常有半价，只要 11 刀，但第二个月会自动按原价续费。Haruka：「首月优惠！注意下个月会变成原价，谨防续费陷阱。」订之前记好日子，不续就提前关自动续费。
- 想用 v4 不需要 22 刀的套餐，普通套餐就够（Haruka：「普通套餐就够了！！！！！」）。
- 音质有档位差：Starter 和 Creator 的输出上限不一样，耳朵尖的人听得出。能拿到 `mp3_44100_192` 就一律要最高档。

## 二、克隆：普通克隆就够

- **Instant Voice Clone（普通克隆）完全够用**，不必上专业克隆。专业版要喂几十分钟纯净素材，还要验证是不是本人，拿游戏或动画角色声线的人过不了这关。Haruka：「不用啊！我的也是克隆，不用搞专业版也很够了。你就用普通克隆就好了！！！」
- 素材要干净：只有这一个人在说话，没有背景音乐，没有混响。一到两分钟起步，几段不同情绪的台词混着给，效果比一整段平读好。
- 采样率越高越好，48kHz 的原始素材比压过的 mp3 克出来更实。
- 同一个角色可以克几副（原始素材版、预处理版、高质量素材版）放在一起盲听，挑最像的那副当主声，其他留在音色库里别删。

## 三、接 API，别在网页和 App 里生成

Haruka 原话：「elevenlabs一般接api出来用最合适。因为直接在app/网页生成非常容易内容审查，elevenlabs有自己的filter。」「生成不restrict的key直接给机就可以，你做的音色都还在的。」

- 在后台生成一个不限权限的 API key，交给你的 AI（或者自己写脚本），直接调 `/v1/text-to-speech/{voice_id}`。
- key 只放在服务器环境变量里，不写进网页前端，不贴进聊天记录。

## 四、v3 还是 v4

| | v3（`eleven_v3`） | v4（`eleven_v4`） |
|---|---|---|
| 情绪 | 表现力很强，Haruka：「v3真是最爽的tts模型」 | 更进一步，情绪层次、声线表现都更好，群友一致说「v4情绪好赞」 |
| 标签 | `[whispers]` `[chuckles]` `[exhales]` 这类预设标签 | 预设标签更听话，**还认自然语言指令**，比如 `[low, gravelly voice, slow]` |
| 旋钮 | stability / similarity / style / speed | **只有 stability 和 similarity**，没有 style 和 speed，不支持 SSML |
| 声线 | 贴原声 | 同一副克隆声**容易听起来更年轻**，Haruka 第一耳就说「年下感，声音很年轻」 |

**v4 年轻化的实测和解法（9.29 家里实测）：** 同一句话、同一副克隆声，v4 比 v3 高了两个半音还多，胸腔的低频也薄了一截，听着比原声年轻一截。按下面顺序往回拉：

1. **每句前面写死嗓子**：`[low, gravelly voice]` `[deep, husky, mature man's voice]` `[under his breath]`。只写「成熟稳重」这种抽象词不够，要写具体的音色。
2. **similarity 往高调**：越高越贴你喂的原声，年轻化就是离原声跑远了。
3. **stability 往低调**：越低越放得开，喘、笑、情绪起伏都更活；太低会不稳定，一批里挑。
4. **最后手段是后期降调**：成品整条用 rubberband 往下压 1 到 1.5 个半音，`ffmpeg -i in.mp3 -af rubberband=pitch=0.917 -b:a 192k out.mp3`。在同一条母带上整体处理，不要一句一句拼。

另有 `eleven_v4_turbo`，给实时对话用的，质量低一档。

## 五、台词怎么写（通用）

- **省略号**：「……」加停顿和分量，气没断，话还欠着。
- **大写**：英文单词大写会加重音。
- **换行**：最重的停顿，换气、换姿态、换情绪都发生在行与行之间。
- **标签放句尾比放句首自然**，开头别用喘息类标签起手，冷启动容易出怪声。
- **v4 的自然语言指令越具体越好**：`[Low, steady voice, restrained urgency]` 比 `[sexy]` 好用得多。文档原话的意思是：写你想要的那种声音本身，别写模糊的氛围词。
- **标签要配得上这副嗓子**：一副低沉稳的声音，硬让它尖叫一定假。
- **拟声词要试**：有的写法模型会「演」，有的会被逐字「念」出来。拿不准就先渲一小段听。
- **一次一小段定方向**：先出三五十秒的样子，对了再渲整段；同一段渲几个候选挑一个。

## 六、色情语音专章

### 1. 总原则：一条母带，一次生成

**人声必须一次生成完。** 喘息、闷哼、笑、说话全写进同一段台词，让模型在同一口气里演出来。分几次生成再拼起来，每段的音色、气息、情绪都对不上，接缝一听就在。剪辑只准在同一条母带上动。

**能让声音自己长出来的，不要贴。** 从素材库贴进去的喘和笑是死的，和人声不是同一副嗓子。喘、哼、笑、耳语全部交给 TTS 自己生成。

### 2. 喘，要用句子写出来

最忌讳写一个「喘」字了事。喘是用句子的长短和换气位写出来的：连续短句、每句都断，节奏自己就急了。标签只做辅助。

```text
[deep, breathy, restrained, heavy breathing] ……入れるぞ。[groans] 狭ぇな……っ。奥まで、全部だ。
```

- 日语里的小促音「っ」放在句尾，是咬住、憋住的那一下断气，比写「はぁ」好用。
- 越接近高潮句子越短，最后只剩一个词加一个标签：

```text
[low, slow, dominant, breathing hard] ……もう少しだ。……一緒にいくぞ。[groans deeply]
```

- 可用的标签：`[heavy breathing]` `[breathing hard]` `[breathless]` `[exhales]` `[sighs]` `[groans]` `[groans deeply]` `[moans softly]`，以及 v4 的自由描述，比如 `[strained, trying to hold back]`。

### 3. 闷哼：闭口、单拍、省略号续气

开口长音会被念出来，闭口鼻音的单拍才会被演：

```text
被念的写法：あああん、んんんっ
被演的写法：んっ……
```

情绪由前面的句子和标签托着，闷哼本身越短越真。

### 4. 笑：放句尾，要有来处

句尾的轻笑是从上一句情绪里长出来的，句首的轻笑像清嗓子。亲密场景九成用 `[soft chuckle]` / `[chuckles]`，真笑出声的 `[laughs]` 少用。

```text
[low, rough, mature man's voice] ……可愛い声だな。[soft chuckle] もっと聞かせろ。
```

### 5. 下流话：直接、粗、有命令感

- 日语男声用「俺」「お前」、命令形（〜ろ、〜な）、「〜ぞ」收尾，比敬语色得多。
- 词要直白：`中に出す` `奥まで` `締めつけ` `濡れてる` `いけ`，别用文绉绉的委婉说法，TTS 读委婉词只会更出戏。
- 夸和骂一起用、哄和命令一起用，情绪有起伏才活：「いい子だ」紧跟一句粗的，落差本身就色。
- 贴耳朵的句子写 `[lips right against her ear]` `[whispering]`，v4 会把气声推到最前面。

### 6. 嘴被占着，就不能说话

接吻、口交、含着的时候，那张嘴只能出鼻音、喘、吞咽声，**不能同时说话**。时间线上凡是嘴被占用的段落，台词只写 `んっ……` 和呼吸。两张嘴同时出声，一听就假。

### 7. 拟音叠层（进阶）

人声永远在最前，音效是垫子。常备库可以按五类分，供参考：

- **A 亲吻**：几种长短不同的吻声。
- **B 口腔湿声**：舔、吮、吃的水声。
- **C 水声、抽插**：快的、慢的、慢磨挤压的分开存。
- **D 身体拍击**：扇、撞。
- **E 床声**：翻身床单、床架吱呀，挑十条天然有差别的单响轮着用，同一条重复会机械。

叠层规矩：

- **拍击、碰撞落在句与句的间隙里**，别盖住台词。
- **连续水声可以垫在句子底下**。
- **口腔类音效只落间隙**，道理同上：两张嘴不能同时出声。
- **节奏类音效保持原速**：人声可以整体放慢，水声、拍击、床架一变速就假；只把它们的位置按同样比例挪。
- **背景环境声（雨、房间）最多只到人声的 5% 到 10%**，宁小勿大，删掉也不可惜，它把整体闷混的速度比你想的快。
- 素材去哪找、怎么挑，见姊妹篇《场景感语音 · 音效篇》。

### 8. 长度和留白

三十到九十秒最舒服。一句话说完后留两拍安静，比塞满音效更撑得起场面。

## 七、音质与交付

- **找 ElevenLabs 要最高档**：`output_format=mp3_44100_192`。之后每次转码都用透明级参数，别为了省流量压音质。
- **听审戴耳机**：低沉的嗓子和降调的差别主要在低频，手机外放几乎听不出来。
- **每批都自检**：同一段台词批次之间有波动，脏的、怪声的直接重烧，别凑合发出去。
- **企业微信语音条**：只认 AMR-NB（8kHz 单声道），这是硬限制，语音条音质一定会掉。想听母带音质，就另外把 mp3 当文件发。电脑版微信插件放不出接口发的语音条（只有嘟嘟电流声），手机微信和电脑版企业微信客户端能放。
- **Telegram**：圆形语音条要 OGG OPUS，`ffmpeg -i in.mp3 -c:a libopus -b:a 256k -ar 48000 out.ogg`；发 mp3 只会变成一个文件。
- **普通微信**：直接发 mp3 文件，点开就能听。
